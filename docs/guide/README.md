# Game and modding guide

Start with [play locally](../../README.md#play-locally). The repository README describes the games and supported content.

Open **Explore all games** below any game picker, or visit `/?guide=games`, for an illustrated introduction to all six games. Each entry explains the workshop name, its genre or inspiration, first moves, goal and controls. **Play** opens the selected game with its existing local save; it does not start a new run.

Use **Look up a term** or `/?guide=glossary` for the [visual glossary](glossary.md): game mechanics, AI policies and experiment language in plain words, with searchable abbreviations and worked examples.

| Task                                                       | Guide                             |
| ---------------------------------------------------------- | --------------------------------- |
| Create a trusted local content pack; preview and replay it | [Modding](modding.md)             |
| Solve, inspect and export a tactical attempt               | [Challenges](challenges.md)       |
| Run deterministic playing engines and compare decisions    | [Playing engines](engines.md)     |
| Play or inspect eight-seat Mixed Rivals                    | [Hearth arena](hearth-arena.md)   |
| Buy, hold and cast Hearth spells                           | [Tavern spells](tavern-spells.md) |
| Inspect/export SVG or 3D assets                            | [Art workflows](../art/README.md) |

Normal play, separate practice branches, imported histories and automated evidence retain their own identities. Current versions and frozen experimental environments are distinguished in the relevant guide; old saves are retained rather than silently migrated.

[Dungeon Cartographer](cartographer.md) covers room drafting, tactical combat, replay saves, and the optional generated Emberwake dungeon.

[Night Passage](night-passage.md) covers the action roguelite prototype, weapons, gods, runes and chronicle saves.
