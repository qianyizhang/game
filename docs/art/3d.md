# 3D object studies

The 3D gallery (`/?art=3d`) presents 29 exportable 3D studies alongside their original live SVG counterparts. The gallery loads saved GLBs: reviewed native DCC deliveries take precedence, and the remaining fixed studies use baked procedural exports. An accepted gallery-scoped publication replaces only its matching study default; workbench publications leave gallery defaults untouched. No gallery load or download runs a procedural constructor.

## Explore and export

- **Copper fox:** `/?workbench=dcc&compare=fox` presents a new fox and five saved
  performances; see the [fox source guide](../../packages/dcc-workbench/subjects/fox/README.md).

- **Canid motion study:** `/?workbench=dcc&compare=canid` compares three new characters
  sharing a saved Blender motion library, including a proportion-retargeted character.
  See the [rig and retargeting pilot](trials/canid-retargeting.md).

- **Evolved Wolf Selector:** Greatwood Wolf provides an alignment selector (**Friendly → Neutral → Evil**) toggling between Bloom Warden, Elder Sentinel, and Thorn Tyrant ([Wolf evolutions record](assets/creatures/wolf-evolutions.md)). Deep links support `/?art=3d&study=wolf&form=<bloom|elder|thorn>`.
- **Viewing controls:** Drag to orbit, scroll/pinch to zoom, named camera buttons, play/pause, playback speed, and scrubbable timeline. Respects `prefers-reduced-motion`.
- **Model Download (GLB):** Exports binary glTF with named meshes, embedded textures, and authored animation clips (excluding plinths/lighting). Skinned creature models use authoritative 3- to 28-bone rigs with anchored roots. Rigid models animate authored node pivots.
- **Capture tools:** **Save animation loop** records 6-second canvas WebM videos. **Save image** captures rendered PNG snapshots.

## Durable sources

| Home                                                | Authority                                                           |
| --------------------------------------------------- | ------------------------------------------------------------------- |
| `packages/dcc-workbench/subjects/<id>/source.blend` | Authoritative working masters, native controls, and delivery briefs |
| `packages/dcc-workbench/registry.json`              | Registered assets, delivery profiles, and sealed publications       |
| `src/art3d/delivery.ts`                             | Resolves accepted gallery releases and supplies original GLB bytes  |
| Procedural builders (`src/art3d/procedural/`)       | Retained bake recipes and construction regressions                  |
| `src/art3d/baked/manifest.json` and adjacent GLBs   | Fingerprinted fixed deliveries and source-input pins                |

### Codebase map

- `src/art3d/catalogue.ts`: Lightweight study IDs, descriptions, motion labels and loop duration. No construction imports.
- `src/art3d/delivery.ts`: Loads accepted native releases or fingerprinted baked GLBs; downloads return the saved bytes. Missing or corrupt delivery fails visibly without regeneration.
- `src/art3d/procedural/factory.ts`: Authoring-only construction and animation entry point for explicit baking and geometry regressions.
- `src/art3d/procedural/catalyst.ts`: Catalyst glass builder.
- `src/art3d/procedural/hydra.ts`, `nightjar.ts`, `phoenix.ts`: Living creature models, continuous skins, subject rigs.
- `src/art3d/procedural/newStudies.ts`: Rigid mathematical shell (Spiral) and pierced metal instrument (Vajra).
- `src/art3d/procedural/prowler.ts`, `wolf.ts`, `matriarch.ts`, etc.: Procedural study definitions with implicit-surface construction via `surfaceSculpt.ts`.
- `src/art3d/procedural/animation.ts`: Sampled procedural playback loops.
- `src/art3d/gallery/Studio.tsx` and `styles.css`: Gallery controls, original SVG comparison and responsive layout.
- `src/art3d/gallery/Viewer.tsx`: React loading, cancellation and status lifecycle.
- `src/art3d/gallery/controller.ts` and `recording.ts`: Gallery rendering, orbit controls, inspection, playback and capture. The controller owns partial-setup cleanup and returns capture functions plus an idempotent disposer.
- `src/shared/three/`: Object guards and asset resource disposal shared with DCC viewers. Original materials remain asset-owned during clay/wire overrides; controllers keep ownership of their override materials.

The procedural backend is absent from the gallery runtime. All 29 studies remain available;
their generators and construction regressions remain available for authoring. Blender
sources, published GLBs and frozen source-path receipts retain their original bytes.
Historical paths resolve through their pinned Git revision; current source links use the
new locations. DCC inspection and comparison retain their own viewer controllers.

## Verification

Choose checks through [gate selection](../engineering/checks.md#gate-selection).
Normal CI verifies saved-file fingerprints and embedded GLB structure without
constructing models. Relevant delivery/viewer changes run lightweight loading for
all baked studies plus representative rendered journeys. Constructor tests run
when their source dependencies change, or during explicit full validation.

### Rebuild fixed studies

```sh
npm run assets:bake
npm run assets:check
STUDY_REBUILD_PARITY=1 npx playwright test --project=functional tests/browser/art3d.spec.ts
```

`assets:bake` uses disposable Chrome and a local Vite server, exports the studies
without an accepted native gallery release, and writes self-contained geometry,
materials, textures and animation clips under `src/art3d/baked/`. It preserves
layer metadata and does not replace native publications. Follow the local browser
execution rules. Review the actual gallery and source/export parity before committing
changed files; GLBs use Git LFS. Exported bytes may depend on the browser's image
encoder, so source pins do not promise byte-identical rebakes across browser versions.

The manifest pins the exporter dependency closure and lockfile, and each GLB's
SHA-256, byte count and motion metadata. `assets:check` rejects stale inputs,
changed bytes, missing files and external resources. A hash proves file identity,
not visual quality or current viewer behavior. The bake is explicit; no build,
normal CI job or user interaction silently regenerates an asset. Native receipt
and review contracts remain separate.

- **Procedural tests:** Verify bone bindings, loop continuity, normalized skin weights, and fixed plinth contacts.
- **Native DCC tests:** `npm run test:dcc` validates contracts and publication isolation. `npm run test:dcc:saved -- --asset <id>` tests native semantic controls across five sample times.
- **Browser tests:** Exercises model loading, animation playback, GLB export, and phone layout.
- **Visual contact sheets:** `npm run test:browser:review -- --grep 'Nightjar|Hydra' --output test-results/review-roundN` generates matched desktop, structure, motion and phone images for human inspection. This opt-in project is separate from functional CI and supplies no automated aesthetic verdict.
- Review history and evidence are tracked in the [asset index](README.md#asset-records), [native pilots](trials/native-pilots.md), and [creature history](creature-history.md).

### Raven: articulated wings and bird support

The [Corven raven study](../../packages/dcc-workbench/subjects/raven/README.md) is
available at `/?workbench=dcc&compare=raven`. Five grounded motions use separate
saved native character/motion masters, deform-only GLB clips and the existing baked
`MotionStudy` viewer. Gallery bird defaults remain unchanged.

Avian folding needs shoulder, elbow and wrist orientation plus feather sweep. Derive
local controls from the intended armature-space folded axes, and inspect both the
folded contour and extended continuous trailing plane. The raven's two-foot audit
measures three forward toes and a hallux through every saved stance interval; hoof
and paw assumptions are not reused. Native edit proof and pixel/motion self-review
remain separate from technical gates.
