# Twelve Scrapyard workshop and enemy concepts

[First six · enlarged/native/compact review](scrapyard-01/review.png) · [Second six](scrapyard-02/review.png)

Twelve unassigned native SVG expansion studies, kept for user selection. They do
not define canonical content, gameplay rules, slots or accepted replacements.
This branch starts at current main and contains only this game family; new Hearth
work and the unmerged first suite are excluded.

## Purpose and reuse

Current `scrapyard/drifter`, `scrapyard/field-repair`, `ui/art-data.ts`, `domain/content.ts` and the installed 20-role suite at base `3a59621` supplied broad worn metal/cloth planes and compact footprints. These six workshop machines and six mechanical enemy silhouettes do not replace any of those roles. Reuse the existing palette and cached-sprite principles before considering later integration.

The user requested useful future-expansion proposals. This package owns saved
source and decision evidence, not another maintained runtime collection. Any later
adoption still needs an owned use, admission/quality review and game-context QA.
No renderer, dependency, defaults, selection or existing consumer changes.

## Review and calls

Author self-review inspected full sheets before extraction and every cell at
38/24px workshop icons and 30/20px isolated enemy views. Fine cable/spring detail weakens, the magnet implies suspension rather than proven contact, and enemy poses skew sideward. Coil Stalker is held for a soft-looking coil/material discontinuity. Crowd/top-down game context remains unreviewed.

Two `gpt-image-2.6-sunburst` calls used high quality/complexity and medium
`gpt-6.1-sol` SVG authoring. Their total usage estimate is **US$0.239614**,
not an invoice. Each `call.json` retains the exact request/prompt, usage, request
ID, grid and review once. Global pool accounting remains with the coordinator.

`original.svg` is the exact return; named child SVGs remove only their cell's
grid translation. The [single staged index](prepared-history.json) owns paths,
digests and lineage. Review PNGs were copied unchanged; full-sheet inspection
renders stay temporary. No duplicate inventory, encoded art JSON or player.

[QA](qa.json) distinguishes vector identity/safety, explicit rasterization edge
differences, isolated registration and review. **Draft blocker: central canonical
registration is pending.** These staged-only records are not merge-ready and do
not establish user aesthetic acceptance or actual game/phone behavior. No merge
or automatic adoption is part of this proposal.
