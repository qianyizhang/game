Use the four theme homes below. Current guides and contracts live here; research and art records label their historical conditions.

| Home                                 | Read it for                                                |

| [Guide](guide/README.md)             | Playing, modding and supported features                    |
| [Engineering](engineering/README.md) | Architecture, commands, maintenance and decisions          |

Session discussions and iteration diaries belong in ignored `.work/sessions/`. Promote durable decisions, limitations and evidence references before closing a session. [Maintenance governance](engineering/maintenance.md) defines checks, document lifecycles and deletion authority.
